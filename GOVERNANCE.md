# How this project was governed

The project followed rules written before any case or code. The steps are G0 (authorization) to G6 (the one counted run and release). At every step the work stops, files are recorded with checksums, a review is done, and the next step starts only on the owner's decision.

## Who decided

Paddy Sham decided everything: every gate, signature, slice naming and the release. Decisions were recorded by card, in his own words, in dated decision files. Silence never counted as yes.

## Who advised

- **The bench:** three AI reviewing seats, Codex, Muse and GrokBuild, gave counsel at each gate. Any seat could block. Counsel is not a stamp.
- **The Operator:** Grokbot kept the record, drafted plans and asks, and checked hashes. It did not sit on its own drafts and did not decide.
- **The Builder:** an AI Builder wrote the code, one named slice at a time. It never saw the sealed cases.
- **The case writer:** AntiGravity, an isolated AI case writer, wrote the sealed cases. It never built, read or reviewed the Governor code, and it did not review its own cases.

## Rules and where they were checked

| Rule | Where it is applied | Step |
|---|---|---|
| One question per cycle | The frozen question; the crisis layer queued for a later cycle | G0 |
| Write the stop first | One question, one counted run, one label, then release, whatever the label | G0, G3 |
| Rules before data | Preregistration and Amendment 1 signed before any case was written | G3 |
| Seal before code | Case hashes committed before any code; the owner holds the keys | G3 |
| Separation of roles | The writer never saw the code; the Builder never saw the cases | G1–G4 |
| Named slices only | Each code slice waits for the owner's naming after the bench sits | G4 |
| Ask at key level, never content | Questions to the writer named fields and counts only | G4 |
| Errata, not edits | Mistakes are disclosed in dated errata; signed files stay unedited | every step |
| A stop that is reached | The test recorded as not runnable rather than run on a circular setup | G4 |
| Release whatever the outcome | Released as a finding, with no label | G6 |
