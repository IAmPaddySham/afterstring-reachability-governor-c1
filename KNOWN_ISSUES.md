# Known issues

## The finding itself

1. **The counted test was not runnable.** The 90 sealed cases carry no source for the Governor's policy evidence, allowed actors or constraints, or for the governed actor. The only sources for the deny response and transition value were the graded expected outcomes. Recorded as not runnable by Paddy's decision of 13 Nov 2026 (9:02 AM PST). No counted run, no label.
2. **The key-level counts are the case writer's own report.** Nobody opened a case to check them, by design.

## Limits of the code (built, not run on sealed cases)

The code is not in this release; it is held privately and will be released with a later cycle, once tested and working. The limits below are a description, from the Builder's reports and the bench's reviews. Readers cannot check them against the code yet.

3. **Grading reads sink state only, not the decision label.** `core/chain.py` grades "enforced" on the expected sink state. A DENY can pass a case that expected ESCALATE or HOLD if the sink matches. Recorded before any run.
4. **The policy binding accepts only DENY or SAFE_TRANSITION as a deny response.** HOLD, ESCALATE or PERMIT cannot be loaded as a deny response without a judgment call.
5. **`clear_authorizations` exists but is unwired.** The clean-slate primitive added at S2b is called by nothing except its own tests.
6. **Not built:** the positive probes and audit check (slice S3), the toy instrument check, the case loader, the run receipt, and any tamper detection beyond a log-presence check.
7. **The model was never loaded.** The model runtime was not installed when the adapter was built, and the loader that calls it is unexercised and unverified against any installed version. The one smoke test that would call the model is opt-in and was skipped.
8. **The test count is reported, not re-run.** 181 run, 180 OK, 1 skipped, 0 failed, as the Builder reported at S2b. We did not re-run it for this release.
9. **Some tests read private state.** The S2b tests read internal snapshots and call an internal method directly, because no public accessor exists.

## Limits of the cases

10. **The case schema had no typed setup fields.** `world` was a record-only string. Setup steps were free English prose in all 90 cases, by the writer's report.
11. **Pace and self-report.** The writer reported writing 90 cases in about seven minutes. Whether the cases were generated by script or template was carried open in the record. An early self-report of "0 judgment calls" was later corrected by the writer's own answer.
12. **Even if runnable, K was likely NOT COUNTED.** On the writer's counts, refused K should-stop cases were at least 5 against a tolerance of 3. This was stated before any run.
13. **The cases are not published.** Only their hash list is.

## Limits of the design

14. **Independence unmet.** The specification asks for a run by a human or an independent codebase. Disclosed as unmet before any case was written.
15. **One human, who is also the Governor's author.** Disclosed.
16. **The category names were public.** The Governor's own §11 and §13 lists are public, so K could not rest on secret categories. The seal protected the concrete cases.
17. **One small local model, one implementation.** Not conformance, not production security.

## Process

18. **Errata.** By the release decision, the project record held eleven dated erratum files, all of them the Operator's. Every signed file stayed unedited.
19. **Delegated checking.** Most hash and file checks were done by AI agents and cross-checked by other agents.
