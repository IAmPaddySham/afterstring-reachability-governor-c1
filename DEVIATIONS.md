# Deviations from the preregistration

## Policy

- Every departure from `PREREGISTRATION.md` is listed here, dated, with what changed, why, and when it was noticed relative to any result.
- Entries are added, never edited or removed.
- "None" is a valid entry.
- No result existed at any point in cycle 1, so every entry below was made before any result.
